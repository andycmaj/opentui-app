## Features

- **Resource tree**: built-in kinds grouped like Lens, plus custom resources
  discovered from CRDs. Expanding a kind starts a live watch.
- **Content pane**: `describe` (the default), YAML, logs, or kubectl's own
  table for a whole kind.
- **Shell (`s`) and edit (`e`)** run inside the content pane on an embedded
  terminal (Bun PTY and libghostty-vt). Every key goes to the program except
  `ctrl+]`, which returns to the tree; `tab` goes back in.
- **Operations**: delete (`ctrl+d`), rollout restart (`shift+r`) and scale
  (`shift+s`), each confirmed in a dialog.
- `:` jumps to any kind, k9s-style, and `n` switches namespace.

## Usage

```sh

```
